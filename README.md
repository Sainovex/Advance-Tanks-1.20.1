# **Advance-Tanks**

An advanced modern military vehicle addon built on the **Superb Warfare** framework for Minecraft 1.20.1 (Forge). 

This mod introduces highly detailed main battle tanks with custom geometry, realistic track animation systems, dynamic vehicle items, and dedicated creative inventory tabs.

---

## 🛠️ Features

* **Custom Tank Models:** Features high-detail vehicle models including the T-90MS and coming soon the modern AbramsX prototype.
* **Realistic Track Animations:** Custom math-driven piecewise linear interpolation (lerp) for smooth, continuous track loops without snapping.
* **Superb Warfare Integration:** Full compatibility with Superb Warfare's entity systems and container block items.
* **Dedicated Creative Tab:** Organized item tab under **Advance Vehicle** for easy access in creative mode.

---

## 📋 Prerequisites & Dependencies

To run or develop this mod, ensure you have:

* **Minecraft:** `1.20.1`
* **Minecraft Forge:** `47.3.0+`
* **Superb Warfare:** `0.8.9.1` Required dependency.
* **Patchouli:** *(Optional)* Required if you want full in-game manual guide support.
